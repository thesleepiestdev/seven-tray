# seven-tray

![Screenshot comparing the Windows 10 Network and Sound system tray icons to seven-tray's Windows 7 tray icon recreations.](https://github.com/user-attachments/assets/094c90e4-9f74-4fc3-9d66-5b9460dc6694)

Recreating older system tray icons in Windows 10/11.

Windows 7 is currently the only OS whose icons are recreated here, this may be expanded in the future.
The basic idea is you can avoid tampering with system files and making your Windows install unstable by simply replacing the system tray icons with this program.
Windows allows you to turn off the built-in versions of these icons (Settings > Personalization > Taskbar > Turn system icons on or off), allowing you to get around having to modify your OS to get the older versions of these simple icons!
If this is useful to even a single other soul I'll consider expanding on it and recreating more icons.
Enjoy!
